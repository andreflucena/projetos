# Projetos

Repositório pessoal organizado por finalidade.

| Pasta | Para que serve |
|---|---|
| [`apps/`](apps/) | Aplicações: sites, apps, APIs, bots, extensões |
| [`scripts/`](scripts/) | Automações e scripts pequenos (Python, shell etc.) |
| [`dados/`](dados/) | Análises, notebooks, SQL, projetos Power BI |
| [`estudos/`](estudos/) | Cursos, exercícios e experimentos |
| [`notas/`](notas/) | Anotações e documentação em Markdown |
| [`arquivados/`](arquivados/) | Projetos antigos ou parados (só para consulta) |

## Convenções

- Nomes de pastas em minúsculas, sem espaços, separados por hífen (`meu-projeto`).
- Cada projeto tem o próprio `README.md` dizendo o que é, como rodar e o status.
- Projetos que crescerem bastante podem ganhar um repositório próprio.
- Nunca versionar senhas, tokens ou arquivos `.env`.

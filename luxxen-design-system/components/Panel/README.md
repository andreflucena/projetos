# Panel
Bloco de conteúdo com borda (`lx-panel`): `surface-raised`, borda `border`, raio `radius-md`, padding `space-6` — os blocos numerados do brand board.

- Abra com um `lx-eyebrow` e siga com título e texto.
- Destaque palavras-chave com `lx-hl-violet` e `lx-hl-blue` (no máximo três por bloco, alternando).
- O consumidor fornece o conteúdo e o grid; entre painéis use gap `space-3`.
- Imagens de linguagem visual (fluxo, conexão, horizonte) ficam à direita, nunca sob texto pequeno.

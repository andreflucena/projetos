# Button
Botão em pílula para ações — `lx-btn` mais uma variante: `lx-btn-primary`, `lx-btn-secondary` ou `lx-btn-ghost`.

- **Primary** (`primary` + `on-primary`, brilho `glow-violet` no hover): uma por tela, para a ação principal ("Fale com um especialista", "Conheça nossas soluções").
- **Secondary** (contorno `border-strong`): ação alternativa ao lado do primário ("Ver casos").
- **Ghost** (texto `accent-blue`): links de ação dentro de cards.
- Tamanho padrão 44px; `lx-btn-sm` (36px) para navbar.
- O consumidor fornece o elemento (`<button>` ou `<a>`), o rótulo e, opcional, um ícone `→` de 16px à direita.
- Rótulos no imperativo, sem ponto final. Nunca dois primários lado a lado.

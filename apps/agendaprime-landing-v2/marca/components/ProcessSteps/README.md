# ProcessSteps
Fluxo de etapas separadas pelo » do símbolo (`lx-step` + `lx-step-sep`): mostra como o trabalho passa pelo agente da luxxen.ai.

- O » entre etapas usa `accent-orange`; as etapas usam `ink`; a etapa do agente luxxen.ai vem em `lx-step-hot` (violeta cheio, texto branco).
- Máximo de cinco etapas por linha; rótulos são substantivos curtos do dia a dia do cliente (consulta, prazo, documento, pedido).
- O consumidor fornece os rótulos e o espaçamento entre grupos.

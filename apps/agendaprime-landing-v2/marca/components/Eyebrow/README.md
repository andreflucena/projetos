# Eyebrow
Rótulo numerado de seção em caixa alta (`lx-eyebrow`, estilo `eyebrow`, cor `label` — cinza no escuro, Midnight no claro), como "01. LOGO PRINCIPAL".

- Use no topo de painéis e seções, numerado com dois dígitos e ponto.
- O consumidor fornece o texto; o CSS aplica a caixa alta e o tracking de 0.18em.
- Não use para títulos de conteúdo — é rótulo, não manchete.

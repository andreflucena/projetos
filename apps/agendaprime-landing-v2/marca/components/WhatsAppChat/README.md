# WhatsAppChat
Celular com tela no estilo WhatsApp (`lx-wa`) para mostrar a conversa entre o cliente e o agente da luxxen.ai.

- Tela de fundo branco; cabeçalho verde `#008069` com ícone e nome do negócio; balão do cliente verde-claro à direita (`lx-wa-out`), do agente cinza à esquerda (`lx-wa-in`).
- Verde e cinza do WhatsApp só aqui: são cores do mockup, não da marca. O resto da peça segue violeta/azul com toque laranja.
- Mostre o celular reduzido, com espaço ao redor, e sempre indique "Conversa ilustrativa" — nunca apresente conversa inventada como caso real.
- O consumidor fornece nome do negócio, mensagens e horários.

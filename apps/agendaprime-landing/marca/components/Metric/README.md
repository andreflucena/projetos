# Metric
Bloco de número grande (`lx-metric`) para resultado mensurável: valor em `accent-orange`, legenda em `ink-muted`.

- Use só com números reais de clientes; enquanto não houver, mantenha o marcador `[X]%` visível — nunca invente métrica.
- Um valor por bloco, 56px, ExtraBold. A legenda diz o que mudou e em quanto tempo.
- O consumidor fornece valor e legenda; em grade, gap `space-3`.

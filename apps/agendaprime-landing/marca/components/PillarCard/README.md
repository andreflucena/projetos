# PillarCard
Card centrado com ícone de linha, título e frase curta (`lx-pillar`) — apresenta os seis pilares da marca ou benefícios de um serviço.

- Estrutura: `.lx-pillar` > `.lx-pillar-icon` (SVG de linha 24×24, traço 1.75) + `.lx-pillar-title` (h3) + `.lx-pillar-text` (caption).
- Ícone em `accent-violet`; use `style="color:var(--accent-blue)"` para alternar em grupos.
- Título de uma palavra; frase de no máximo duas linhas, com ponto final.
- O consumidor fornece o ícone (Lucide como referência), título, texto e o grid (3 ou 6 colunas, gap `space-3`).
